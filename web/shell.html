Both screens take taps: on the top one, tap a setting to pick it and drag sideways to change it, or tap a style or patch in the browser.
Keyboard: arrows = D-pad, I J K L = circle pad, X = A, Z = B, S = X, A = Y, Q / W = L / R, 1 / 2 = ZL / ZR, Shift = SELECT, Enter = START.
Game controller (Bluetooth or USB): buttons in Nintendo positions, left stick = circle pad, right stick = C-stick, bumpers = L / R, triggers = ZL / ZR (ZR plays / stops, ZL records). MIDI plays it from a controller (Chrome / Edge on a computer, or the Web MIDI Browser app on iPhone). Your sounds and drum grid are kept in this browser. Turn the phone sideways for the wide layout.
PHONE LINK: on the phone, scan this (or open the address)
